Tentang panduan ini

Panduan operasional untuk pemilik usaha, kasir, desainer, operator produksi, dan staf keuangan percetakan. Setiap bagian ditulis sebagai alur kerja, bukan sekadar daftar tombol.

Untuk pemasangan dan konfigurasi server, lihat INSTALASI.md (INSTALASI.md). Untuk detail teknis, lihat ARSITEKTUR.md (ARSITEKTUR.md).
