Mode Offline dan Sinkronisasi

3 bagian · ±3 blok pencarian

25.1 Cara kerja

  • Saat offline, transaksi tetap dapat dibuat pada mode API dan disimpan di antrean lokal.
  • Saat koneksi kembali, antrean dikirim otomatis atau manual dari indikator sync.
  • Data yang gagal dikirim tetap di antrean dan dicatat di riwayat sinkronisasi.

25.2 Menangani antrean

  1. Buka indikator sync di footer/header.
  2. Periksa item yang tertunda beserta pesan error.
  3. Pastikan koneksi stabil, lalu pilih Sinkronkan.
  4. Jika satu item gagal terus, periksa data (mis. pelanggan/produk yang tidak ada di server) dan pesan error.
  5. Jangan membersihkan data peramban sebelum antrean kosong.

25.3 PWA dan cache

Aplikasi dapat dipasang sebagai PWA. Saat ada versi baru, aplikasi membersihkan cache lama dan service worker secara otomatis. Jika tampilan terasa “nyangkut” setelah pembaruan, muat ulang paksa (Ctrl+Shift+R).
