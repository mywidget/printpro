    Tim Marketing

    1 bagian · ±2 blok pencarian

    Jika toko memakai marketing/afiliasi:

    1. Daftarkan anggota tim marketing.
    2. Hubungkan order dengan marketing yang menangani.
    3. Pantau performa: jumlah order, nilai penjualan, dan komisi.
    4. Gunakan laporan marketing untuk evaluasi dan pembayaran komisi.

    Pastikan aturan komisi disepakati sebelum order dicatat agar tidak terjadi sengketa.

    Alur CRUD tim marketing

    1. Lihat daftar — Menu Tim Marketing menampilkan filter cabang, tombol AGENT BARU, tab PERFORMA & TIM SALES, RIWAYAT & PEMBAYARAN KOMISI, dan BROADCAST WHATSAPP PELANGGAN, pemilih BULAN PERFORMA, kartu performa tiap agent, serta tabel DAFTAR AKTIF MARKETING.

    2. Tambah agent — Klik AGENT BARU. Panel TAMBAH AGENT terbuka dengan bagian PENGATURAN TARGET & KOMISI.

    3. Isi data agent — Isi NAMA LENGKAP, WHATSAPP, TARGET BULANAN, dan KOMISI (%), lalu tentukan STATUS serta CABANG.

    4. Simpan dan verifikasi — Klik SIMPAN AGENT. Notifikasi Berhasil muncul, lalu kartu performa dan baris tabel agent baru langsung tampil.

    5. Ubah agent — Klik ikon pensil pada kolom AKSI di baris agent. Panel EDIT AGENT terbuka dengan data sebelumnya sudah terisi.

    6. Verifikasi perubahan — Ubah data yang diperlukan (mis. nama atau komisi), klik SIMPAN AGENT, lalu pastikan perubahan tampil pada tabel dan kartu performa.

    7. Hapus agent — Klik ikon tempat sampah pada kolom AKSI, lalu tekan Ya, Hapus! pada dialog Hapus Agent?. Dialog mengingatkan bahwa data performa agent ikut hilang dari laporan.

    8. Verifikasi penghapusan — Muat ulang halaman. Agent uji tidak lagi muncul dan jumlah baris kembali ke semula.

    Gunakan tab RIWAYAT & PEMBAYARAN KOMISI untuk melihat komisi siap cair dan mencatat payout, serta PENGATURAN KOMISI untuk mengatur aturan komisi default. Hapus agent hanya jika memang tidak diperlukan; menonaktifkannya lewat STATUS → INACTIVE lebih aman agar riwayat performa tetap utuh.
