    Penawaran Harga (Quotation)

    1 bagian · ±2 blok pencarian

    Quotation dipakai sebelum pelanggan menyetujui order.

    1. Buka Penawaran Harga.
    2. Pilih pelanggan dan tambahkan item seperti membuat order.
    3. Atur masa berlaku penawaran.
    4. Simpan dan kirim PDF/tautan ke pelanggan.
    5. Jika disetujui, konversi menjadi order agar tidak perlu mengetik ulang.

    Alur CRUD penawaran harga

    1. Lihat daftar — Menu Penawaran Harga menampilkan tabel dengan kolom ID / Tanggal, Pelanggan, Masa Berlaku, Item, Grand Total, Status, dan Aksi Kerja. Di atasnya ada pencarian ID/nama pelanggan, filter status Semua / Menunggu / Disetujui / Ditolak / Jadi Order, rentang tanggal, dan batas halaman.

    2. Buat penawaran baru — Klik + Buat Penawaran Baru. Modal Buat Penawaran Harga Baru 📝 terbuka dengan tiga blok: 1. Profil Pelanggan, 2. Rencana & Kelengkapan, dan 3. Tambahkan Layanan & Spesifikasi. Keranjang masih kosong (RINGKASAN KERANJANG (0 ITEM)).

    3. Isi pelanggan dan layanan — Lengkapi Nama Pelanggan, No Handphone, Level Member (berpengaruh pada harga), dan Cabang Penawaran (Kop Surat). Pada blok 2 tentukan Masa Berlaku Penawaran*, opsi Diskon Potongan IDR/%, Aktifkan PPN, serta Catatan Ekstra Penawaran. Pada blok 3 pilih layanan dari Pilih Katalog Layanan, isi Jumlah Qty, tambah ukuran Panjang/Lebar untuk layanan DIMENSION dan Spesifikasi Tambahan, lalu klik + Tambah Layanan.

    4. Simpan dan verifikasi — Klik Simpan Penawaran. Notifikasi Sukses — Penawaran harga berhasil disimpan. muncul dan nomor penawaran dibuat otomatis (mis. QT-1793548978228) dengan status awal Menunggu.

    5. Ubah penawaran — Klik ikon Edit data penawaran (pensil) pada baris. Modal Edit Penawaran Harga 📝 menampilkan data yang tersimpan, termasuk item pada keranjang. Tambahkan nilai Diskon Potongan, misalnya 40000.

    6. Verifikasi perubahan — Klik Simpan Perubahan. Notifikasi Sukses — Penawaran harga berhasil diperbarui. muncul dan baris daftar langsung menampilkan total baru.

    7. Hapus penawaran — Klik ikon Hapus Penawaran (tempat sampah) pada baris, lalu tekan Ya, Hapus pada dialog Hapus Penawaran?.

    8. Verifikasi penghapusan — Notifikasi Dihapus — Data penawaran telah terhapus. muncul dan daftar kembali kosong.

    Tindakan lain pada setiap baris: Pratinjau Surat Penawaran, Unduh File PDF Penawaran, Share via WhatsApp, dan Proses Order untuk mengubah penawaran yang disetujui menjadi order POS. Status dapat diubah langsung dari dropdown Menunggu / Disetujui / Ditolak; tombol edit tidak tersedia lagi setelah penawaran berstatus Jadi Order, dan Proses Order tidak aktif untuk penawaran yang ditolak atau sudah kedaluwarsa.

    Catat revisi harga pada catatan agar riwayat negosiasi jelas.
